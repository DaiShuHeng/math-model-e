# 本目录的代码布局

## `code_最终模型/` —— 队友的完整代码，**已在克隆中实跑验证**

包含 `config.py`、`models.py`、`inference.py`、`io_utils.py`、`explain_v2.py`、
`shapley_exact.py`、`integrated_inference.py` 等 24 个文件，是**产出仓库全部交付数字**的代码。

已从 GitHub 克隆到干净目录后实跑：

```bash
export MATH_E_DATA=/path/to/包含附件1..附件4的目录
cd E题_复核修订工作包/02_模型与代码
python code_最终模型/integrated_inference.py --out /tmp/out
# -> 附件3_预测.csv(30行) + 附件4_预测与解释.csv(20行) + 预测汇总.json
```

**注意必须在 `code_最终模型/` 内运行**：脚本用 `sys.path` 相对自身位置找 `config.py`，
单独把脚本拷到别处会报 `No module named 'config'`。
