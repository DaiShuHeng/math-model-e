## 3 部署模型

p2 三种子概率集成 + **仅用验证集拟合**的决策偏置 `[-0.2, 0, 0]`。
在 `aligned_50.pkl` 的 test 划分(n=727)：Accuracy 0.6754 / Macro-F1 0.6485 /
MAE 0.6145 / Pearson 0.6912。

## 4 核心实测：证据排序

| 模态 | 遮挡排序(集合删除下降) | 注意力排序 | top-5 相同 |
|---|---:|---:|---:|
| 文本 | **+0.1528**(20/20为正) | +0.0771(7条非正) | 0/20 |
| 语音 | **+0.0075**(17/20为正) | −0.0048(13条非正) | 0/20 |
| 视觉 | −0.0025(11/19为正) | −0.0070(12条非正) | 0/20 |

三模态一致地：遮挡排序优于注意力排序，且两者 top-5 **无一条相同**。
视觉的单点局部证据平均为负——说明视觉作用来自分布层面的整体偏移，
而非可定位的局部片段。论文已如实写明，不把 Shapley 份额当作局部证据。

## 5 复现

```bash
export MATH_E_DATA=/path/to/包含附件1..附件4的目录

# 重新生成三模态证据交付件
cd 02_模型与代码
python integrated_inference_full.py --out ../01_交付结果

# 重新应用论文格式修订(幂等)
python apply_paper_fixes.py ../03_论文与文档/数模论文_数据复核修订稿.docx \
       --out ../03_论文与文档/数模论文_数据复核修订稿.docx

# 11 道核验门
cd .. && python 04_核验/verify_revision.py
```

## 6 边界

- 附件3、4 **无标签**，不能计算专项集准确率。
- 语音/视觉的时间是**对齐槽时间窗**（按音轨时长等分50槽），**不是测得的事件起点**；
  CSV 的 `mapping_status` 列已注明。
- 附件4 的证据位置仍需**人工回看原始音视频**确认；本包给出词、秒、帧号是为了
  让核对更快，不代替人工核验。
- 附件3 不提供 768 维 `text` 字段，其文本经冻结 BERT 从 `text_bert` 编码；
  该字段不对称由赛题文件决定，不是实现选择。
