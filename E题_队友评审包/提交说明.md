# E 题提交说明（复现指南与产物清单）

## 1. 目录结构

```
E题_submission/
├── solution/                      # 主求解仓库（Q1 加固、Q2 冠军模型、Q3 精确 Shapley、论文）
│   ├── paper/论文.md               # 论文（含 figures/ 三图）
│   ├── src/                       # 全部求解代码（见论文附录 A）
│   ├── results/                   # 附件 3/4 预测与归因 CSV、Q1 探针结果
│   ├── logs/                      # 消融/对抗/退化曲线等机器可读结果（论文全部表格的原始数据）
│   ├── data/p1_features_v3/       # 问题一 YuNet 版特征（100 条 NPZ + 汇总 CSV）
│   └── tests/run_tests.py         # 7 项验收测试（附件3签名、损伤重放、确定性…）
└── math_model_e_optimized/        # 基线与 Q1 基础流水线仓库（CTC 对齐、特征提取、p2/p3 基线）
    ├── code/                      # 对齐、特征、训练、解释与交付构建代码
    ├── models/                    # p2/p3 基线小模型头权重（每个约 1.9 MB）+ 标定文件
    ├── results/                   # 基线全部结果表（含 附件3_优化预测.csv、附件4_优化预测与解释.csv、evidence_time_mapping.csv）
    └── data/                      # CTC 对齐 JSON（120 条）、p1_features（Haar 版 v2）
```

代码不包含任何个人身份信息；两仓库为同一参赛队伍的全部工作。`$E_ROOT` 指本目录。

## 3. 复现顺序

```bash
# Q1（基础特征 + 对齐：math_model_e_optimized 仓库）
python code/align_media.py && python code/p1_refine.py            # Haar 版 v2
cd ../solution
python -m src.p1_vision_enhance                                   # YuNet 视觉加固 → v3
python -m src.p1_validation_v3                                    # 分组 CV 探针（论文表 4.5）

# Q2（冠军 q2_base_cw：冻结 bert-base + 机制匹配增强 + 类加权 + 门控融合）
python -m src.train_q2 --bert-dir $E_ROOT/models/bert-base-uncased \
    --freeze-text 1 --cls-weight 1 --out weights/q2_base_cw        # ×3 种子 2026/7/42
python -m src.eval_q2 --ckpt weights/q2_base_cw/s*/best.pt         # 退化曲线
python -m src.eval_variants --ckpt ...                             # 类型/位置/时长网格
python -m src.head2head && H2H_SPLIT=test python -m src.head2head  # 对抗对比（valid/test）
python -m src.final_test_eval                                      # 测试集一次评估
python -m src.predict_att3                                         # 附件 3 预测

# Q3
python -m src.q3_shapley                                           # 附件 4 精确 Shapley

# 验收
python tests/run_tests.py
```

评估纪律：仅 train 拟合统计量；valid 选型；test 在配置冻结后仅评估一次；附件 3/4 无标签、仅推理。
