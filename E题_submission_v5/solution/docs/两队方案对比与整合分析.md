## 3 他赢在哪里：三个原因，按重要性排序

### 3.1 重建辅助目标（最重要）

他的损失函数在"**原本有效、被本次增广人为遮蔽**"的位置上增加重建项：

```python
target_mask = (M_natural[m] > 0) & (M_obs[m] <= 0)      # 自然有效 但 本次被遮蔽
loss_rec += smooth_l1(pred[target_mask], X_true[target_mask]) / (count * DIM[m])
```

自然补零的位置**不参与**，所以模型学的是"从其余模态与被遮位置之外的上下文，把被遮住的
真实特征补回来"。这个梯度直接约束融合表示必须保留可逆的模态内容，而不只是够分类。

### 3.2 可学习缺失令牌（在他的增广下有效，在我的增广下无效）

他的编码器用可学习向量替换零行：

```python
h = self.proj(x) * m + self.missing_token * (1.0 - m)
```

我的 v5 用零行 + 门控关闭。在他的增广族（rate × 模态子集 × 1–3 段）下单独加进我的模型，
得到 **+0.0095** valid 选择分数，是四个被考察改动里唯一为正的。

**但换到我的生产增广协议（`span_bounded_v1`，观测支撑内单连续块）后这个增益消失了。**
我按生产入口训练了 6 个缺失令牌模型（v5e/v5f × 3 种子）：

| 组 | 模型数 | valid clean Macro-F1 均值 | 标准差 | 最好 |
|---|---:|---:|---:|---:|
| 原 v5a–v5d | 12 | 0.6239 | 0.0070 | 0.6368 |
| 缺失令牌 v5e–v5f | 6 | 0.6238 | 0.0032 | 0.6287 |

**均值差 −0.0001，即完全没有效果。**缺失令牌的收益与增广方式耦合：
在他的"多子集、多段、高缺失率"增广下缺失表示被反复训练，才有价值；
在我的"观测支撑内单块"增广下缺失模式单一，学不学这个向量没有区别。
这一条是本次分析里**被自己后续实验推翻**的结论，如实保留。

### 3.3 选择准则的口径不同（解释了为什么 valid 排名不同）

| | 选择分数 |
|---|---|
| 他 | `valid_f1_macro − 0.5 × (valid_MAE / 3)` |
| 我 | `mean(clean MacroF1, 连续 TAV r20 MacroF1)` |

他的准则把 MAE 作为一半权重的惩罚项，因此**直接优化强度回归**；我的准则只看分类，
完全不管 MAE。这正好对应 §2 里两项差距的分布：分类打平、MAE 落败。

我按他的准则在 valid 上重排全部 14 个候选模型，**他的 p2 仍然是第一名**（他的准则分
0.5383，我最好的 v5_c3_s2026 是 0.5288）。所以这不是"选错了模型"，而是他的模型在
MAE 上确实更强。

## 4 我做了哪些整合实验（以及哪些被证伪）

### 4.1 被证伪：他的融合结构搬到我的模型上反而更差

我把他的"模态序列按 α 混合成融合序列 + Transformer + 重建"机制完整实现进我的模型，
用同一套增广、同一预算、同一选择分数，2 个种子：

| 变体 | valid 选择分数 | test 原始 Macro-F1 |
|---|---:|---:|
| 我的池化式（对照） | 0.6217 | 0.6208 |
| 序列融合 + Transformer | 明显更差 | — |
| 序列融合 + 重建 | 明显更差 | — |
| 序列融合 + 重建 + 缺失令牌 | 0.6068 | 0.6095 |

**结论：融合结构本身不是他的优势来源。**他的 d_model=96、1 层 Transformer 在我的数据
划分与增广下过拟合；优势来自训练目标（重建）与缺失令牌，不是融合方式。

### 4.2 四个改动逐个移植：全部无收益

| 变体 | valid 选择分数（种子 2026，他的增广族） |
|---|---:|
| 我的基线 | 0.6217 |
| + 重建项 | 0.6211 |
| **+ 可学习缺失令牌** | **0.6312** |
| + 标签平滑 0.05 | 0.6116 |
| + 门控先验 log(avail) | 0.6264 |
| 全部叠加 | 0.6230 |

单种子噪声约 ±0.007。表面上只有"缺失令牌"为正，但把该结论搬到生产增广协议后
6 个模型的均值差是 **−0.0001**（见 §3.2）。因此**这四个改动在我的架构上都没有可迁移的收益**；
重建项与标签平滑在两种增广下都边际为负，门控先验接近持平。
真正的差距（MAE 0.045）来自**重建目标与整个训练配置的组合**，而不是可以单独摘出来的模块。

### 4.3 被证伪：跨队集成没有收益

用 valid 贪心前向选择（允许校准），14 个成员（我的 12 个 + 他的 p2/p3）：

| 组合 | 成员数 | valid 校准 F1 | test 校准 F1 |
|---|---:|---:|---:|
| 贪心选择 | **1** | 0.6422 | 0.6486 |
| 他的 p2 单独 | 1 | 0.6422 | **0.6486** |
| 我的 v5 top4 | 4 | 0.6390 | 0.6433 |
| 我的 v5 top4 + p2 | 5 | 0.6324 | 0.6408 |
| 全部 14 个 | 14 | 0.6272 | 0.6432 |

**贪心选择只挑了他的 p2 一个模型就停了**——两队的错误高度相关（同一份对齐特征、同一个
任务），集成只会把弱成员平均进来。**不要做跨队集成。**

### 4.4 校准的可靠性：必须如实说明

他的 `p2` 用 valid 拟合的偏置是 `[-0.2, 0.0]`，在 test 上带来 +0.0051 的 Macro-F1。
我做了完整审计：

| 模型 | valid 选的偏置 | valid 增益 | **test 迁移增益** | test 上的最优（oracle） | 网格中会伤害 test 的比例 |
|---|---|---|---:|---:|---:|---:|
| 队友 p2 | [-0.2, 0.0] | +0.0058 | **+0.0051** | +0.0051 | 56% |
| 队友 p3 | [0.2, -0.2] | +0.0062 | **−0.0174** | +0.0249 | 44% |
| 我的 v5 top4 | [-0.2, 0.0] | +0.0034 | +0.0195 | +0.0195 | 56% |

三点结论：

1. 校准增益**很小且脆弱**：25 个候选偏置里有 56%（p2）/ 44%（p3）会**降低** test 成绩。
2. 他的 **p3 校准实际是亏的**（−0.0174）。p3 报出的 0.5874 是校准后的数字，
   校准前是 0.6048——也就是说他的问题三成绩被自己的校准拉低了。
3. 校准必须在 valid 上拟合、冻结后再跑 test，他确实是这样做的（`evaluate_final.py`
   注释写明 "Bias frozen before test predictions"），**流程合规**，但收益不能当成模型能力。

### 4.5 选择准则的移植：几乎没有效果

我把早停准则换成他的 `f1 − 0.5×mae/3`，三个种子：

| 准则 | valid F1 | valid MAE | test 原始 Macro-F1 | test MAE |
|---|---:|---:|---:|---:|
| 我的（clean + r20） | 0.6260 | 0.6234 | 0.6198 | 0.6596 |
| 他的（f1 − 0.5·mae/3） | 0.6259 | 0.6185 | 0.6190 | 0.6577 |
| 他的准则 + 加强回归权重 | 0.6070 | **0.6165** | **0.6304** | 0.6494 |

**换准则基本不改变结果**（valid MAE 仅 0.6185 vs 0.6234）。这说明 0.045 的 MAE 差距
**不是选出来的，是练出来的**——他的重建目标真的让回归头更强。这一点很关键：
它排除了"只要换个选型口径就能追上"的可能。

### 5.1 证据定位的正面对比（结论比预期保守）

他用 `p3` 的注意力池化权重（`explain_v2.py` 的 `beta`）选证据词；我用全位置遮挡扫描
（逐位置删除、按所解释类别概率的下降量排序）。两种排序在**我的模型**上 top-5 无一相同，
但"排序不同"不等于"我的更好"。所以我做了公平对照：**把双方的证据位置拿到同一个模型上，
一起删除，比较类别概率的下降量**。

| 评价方式 | 队友证据位置 | 我的遮挡证据位置 |
|---|---:|---:|
| 在**我的模型**上删除（自有模型） | 0.0384 | **0.0670** |
| 在**他的 p3** 上删除（自有模型） | 0.0553 | 0.0519 |
| 逐样本均值 | 0.0553 | 0.0670 |
| 中位数 | 0.0347 | **0.0466** |
| 出现**负效应**（删了反而更自信）的样本数 | 2 | **0** |
| 逐样本胜出（我的 > 他的） | — | 3/20（在他的 p3 上） |

配对差在他的 p3 上为 **−0.0034，95% bootstrap CI [−0.0173, +0.0166]，包含 0**。

**如实结论：两种证据定位在他的模型上统计上不可区分。**我之前"注意力排序不可靠"的说法
只在**我自己的模型**上成立（相对提升 +74%，16/20 胜出）；一旦换到解释它的那个模型上，
优势就缩小到 +21% 的均值差且不显著。

唯一稳定成立的差别是**稳健性**：他的证据集在 2 条样本上给出负效应（删掉之后模型反而
更确信），我的遮挡排序在 20 条上**没有一条**为负。也就是说遮挡排序不会给出方向性错误的
证据，这是可以主张的；"更准确"则不能主张。替换他那一列仍然值得做，但理由是消除负效应，
不是提升幅度。

## 6 整合建议（按性价比排序）

1. **以他的 p2 作为主预测模型。** 它在 valid 与 test 两个口径、分类与回归两类指标上都不
   弱于我，且我之前只把它当教师。这一步是纯收益。
2. **他的问题三成绩应当改用未校准的数字（0.6048 Macro-F1）或重新拟合校准**：
   `p3` 的验证集校准在 test 上是 **−0.0174**（§4.4）。p2 的校准是 +0.0051，可以保留。
3. **不要把模块单独摘出来移植。** 我逐个移植了他的四个想法（重建项、缺失令牌、标签平滑、
   门控先验），**没有一个在我的架构上产生可迁移的收益**（§3.2、§4.2）。差距来自
   "重建目标 + 他的增广族 + 他的选择准则"这一整套组合，要提 MAE 就得整体采用。
4. **用全位置遮挡扫描替换他的注意力证据排序——理由只是消除负效应。**
   公平对照（§5.1）显示两种定位在他的模型上**统计上不可区分**（配对差 −0.0034，
   CI 含 0），所以不要声称"更准"。可以声称的是：他的证据集在 2/20 条样本上出现
   **负效应**（删掉证据反而更自信），遮挡排序在 20 条上为 0。替换的成本很低，
   收益是"不会给出方向性错误的证据"。
5. **不要做跨队集成**（§4.3 已证伪）；**不要把校准当成绩**（§4.4 已量化）。
6. **把他的 `附件3` 结果与我的 token 路径结果交叉核对。** 两者在 30 条里只有 20 条一致，
   分歧集中在 10 条边界样本；他的中性预测偏多（17 vs 11）。这 10 条值得人工回看原始音视频。
7. **保留我的打包验收与回归测试。** 他的包缺独立加载验收与掩码一致性测试；
   我这边可以直接把他的权重纳入同一套 G1–G6 门。
