## 3 复现步骤

```bash
# 0) 环境：Python 3.11+、numpy、torch(CPU 即可)、scikit-learn、scipy、pandas
python -m pip install numpy torch scikit-learn scipy pandas

# 1) 指向赛题数据目录（包含 附件1..附件4）
export MATH_E_DATA=/path/to/E题数据

cd solution

# 2) 回归测试（30 项）
python -m tests.run_tests

# 3) 重新打印缺失结构审计全部统计量
python -m src.audit_missing_structure

# 4) 复现验证集成绩（只读 train/valid）
python -m src.train_q2_feature --plan
python -m src.train_q2_feature --variant v5a --seed 2026 --out /tmp/v5a_s2026

# 5) 复现附件 4 预测与解释（部署子集见 weights/v5_deploy/selection.json）
python -m src.explain_att4_v5 \
  --ckpt weights/v5_deploy/c0_s2026.pt weights/v5_deploy/c2_s2026.pt \
         weights/v5_deploy/c2_s42.pt weights/v5_deploy/c3_s2026.pt \
  --out /tmp/att4.csv
```

## 4 推断接口的两个注意点

1. **附件 3 没有 768 维 `text` 字段**（只有 `text_bert`、`audio`、`vision`），因此
   特征级路径不能用于附件 3；附件 3 的预测沿用 token 编码器路径的结果
   （`results/att3_predictions_final.csv`）。论文 §5.3 如实报告该字段不对称。
2. **训练、验证、附件 4 使用同一对齐特征版本**（`aligned_50`）与同一 50 位置掩码接口，
   满足赛题"保持同一特征版本和同一输入接口"的要求。
