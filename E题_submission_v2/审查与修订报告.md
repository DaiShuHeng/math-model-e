- Q3 原 CSV 有 20 行。用八联盟概率重算分类 Shapley，最大绝对差约 0.00001，符合五位小数舍入。Shapley 的计算公式可保留。
- 当前附件 2 `aligned_50.pkl` 为 746,061,824 字节，实际反序列化报 `pickle data was truncated`。它不是“路径不对”，而是当前副本不完整。原先核验的完整文件为 993,842,861 字节；最终应以源文件校验和和成功加载为准。

### 历史结果中可直接纠正的数字

`q2_base_cw` 相对 `q2_base_cw_noaug`（同一个旧协议的三种子均值）：

|指标|clean 差值|旧 r20 差值|
|---|---:|---:|
|Accuracy|+0.183 个百分点|+2.793 个百分点|
|Macro-F1|+0.107 个百分点|+2.506 个百分点|
|MAE|+0.02020（变差）|−0.01433（改善）|
|Pearson|−0.00930|+0.02152|

因此原稿“clean −0.2/−0.1pt”符号写反；“几乎无代价”还忽略了干净强度回归变差。三种子标准差不是视频总体的置信区间。q2→q2_base_cw 同时改变编码器与类别权重，不是纯编码器消融。

验证集多数类基准是 338/728≈0.4643，不能拿测试集 362/727≈0.498 的值解释验证集曲线。旧增强 P_FILE=0.9 且率池有 10% 零值，非零率被选中的概率为 0.81；取整还可能使短句不实际损坏，不能写“90%样本损坏”。

## 三、建议保留的论文主线

不建议再叠加更多网络名称。围绕“可核验对齐 → 连续局部缺失鲁棒性 → 可复核决策证据”形成三项闭环：

1. Q1 用现有 100 条结果，明确各维物理定义和时间窗汇聚。视觉是面部网格变化代理，不是已验证 AU；人脸命中率不是情感预测准确率。正文给完整 100 行汇总并选择高置信和低置信样本回看。附件 1 的 50 个物理时间窗与附件 2 的 50 个 token 位置必须区分。
2. Q2 先做可交付的 Tiny 编码器单模型，再在验证集决定是否需要集成；从开始就核算含编码器的 50MB 预算。保留主模型的缺失掩码、门控和分类/回归双头。主验证网格是缺失类型×块位置×比例；散布缺失只作额外压力对照。P_FILE=0.7 等是本次设计起点，不是“已验证最优参数”。
3. Q3 保留精确 Shapley，但固定所解释类别、说明空联盟基线及负贡献。局部特征遮挡与原始词语干预分开报告。时间映射先做 token 对齐一致性检查，再回看原始音视频；低置信样本标记人工复核，不把 token 索引直接换算成视频秒数。
4. 实验按相同编码器、相同种子、相同训练预算逐项消融：无增强/连续增强、固定/学习门控、类权重开关、是否回归任务。以验证集 clean 与连续缺失 Macro-F1 的预先固定均值选模型，同时报告 MAE；在冻结选择后运行 test 和专项推断。

## 五、文献借鉴的边界

本次未把未经核验的网络“获奖论文”当作质量证据。与缺失模态直接相关的可核验原始研究包括 [MissModal（TACL 2023）](https://aclanthology.org/2023.tacl-1.94/) 和 [Multimodal Prompt Learning with Missing Modalities（ACL 2024）](https://aclanthology.org/2024.acl-long.94/)。前者可供考虑完整/缺失表示一致性约束，后者涉及提示学习；它们不是本竞赛获奖论文，其外部数据或整模态缺失设置也不能直接套成本题局部连续缺失实验。当前优先完成干净的基线与受控消融，暂不增加未经验证的额外模块。
